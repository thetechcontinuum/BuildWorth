# Evaluation Benchmark & Auto-Publication Gate

## Benchmark Acceptance Thresholds

Automatic unattended publication is permitted ONLY if a 100-opportunity sample achieves:

1. **Unsupported Claim Rate**: $\le 2.0\%$
2. **Buyer Definition Quality**: $\ge 95.0\%$
3. **Score Calibration Error**: $\le 5.0$ points average
4. **Evidence Relevance Precision**: $\ge 90.0\%$
5. **Duplicate Rate**: $\le 1.0\%$
